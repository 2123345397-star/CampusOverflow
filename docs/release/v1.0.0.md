## 3. 部署步骤

```bash
# 1) 只起应用（MySQL/Redis/后端/前端）
docker compose -f deploy/docker-compose.yml up -d --build

# 2) 看健康检查
curl http://localhost:8080/actuator/health

# 3) 演示账号
# 学生：登录页自助注册
# 教师/管理员：按 README 1.1 的 SQL 提权 demo 账号，或 demo profile
```

- 前端：compose 内 nginx；开发模式 `cd frontend && npm run dev`。
- 数据库：Flyway 自动建表；中文检索依赖 compose MySQL 的 `ngram_token_size=2`。
- 冒烟：`http/auth.http` → `http/qa.http` → `http/discovery.http`。

## 4. 升级/兼容

- 新增 `processed_event` 消费幂等记录与搜索投影表；Flyway 自动迁移，无需手工改表。
- 禁用账号后旧会话会被删除；用户需要重新登录（且无法登录禁用账号）。
