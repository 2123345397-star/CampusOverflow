## 4. 部署步骤

```bash
# 1) 完整环境（含 Prometheus + Grafana）
docker compose -f deploy/docker-compose.yml --profile observability up -d --build

# 2) 仅应用（MySQL/Redis/后端/前端）
docker compose -f deploy/docker-compose.yml up -d --build

# 3) 健康检查
curl http://localhost:8080/actuator/health/readiness
```

- 前端：compose 内 nginx（`http://localhost`）；开发模式 `cd frontend && npm run dev`。
- 数据库：Flyway 自动迁移；中文检索依赖 compose MySQL 的 `ngram_token_size=2`。
- 演示账号：学生自助注册；教师/管理员用 demo profile 或按 README 1.1 的 SQL 提权。
- 冒烟：`http/auth.http` → `http/qa.http` → `http/discovery.http`，或 `scripts/smoke/`。
- 监控：Prometheus `http://localhost:9090`，Grafana `http://localhost:3000`（admin/admin，首次登录改密）。

## 5. 升级 / 兼容

- 新增 `processed_event` 消费幂等记录与搜索投影表，Flyway 自动迁移，无需手工改表；
- 禁用账号会删除该用户 Redis 会话，用户需重新登录且无法再登录；
- 事件契约只增不改；旧数据无需回填，搜索索引按新事件增量维护。
