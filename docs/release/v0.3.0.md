## 4. 部署步骤（一键）

```bash
# 完整环境（含 Prometheus/Grafana）
docker compose -f deploy/docker-compose.yml --profile observability up -d --build
# 仅应用（MySQL/Redis/后端/前端）
docker compose -f deploy/docker-compose.yml up -d --build
```

- 后端 `http://localhost:8080`（健康检查 `/actuator/health`）；前端走 compose 内 nginx。
- Flyway 自动建表（`ddl-auto: none`）；中文全文检索依赖 compose 内 MySQL 的 `ngram_token_size=2`，自建库需对照参数。
- 演示数据：`demo` profile（`DemoDataSeeder`）；测试账号与提权方式见 README 1.1 节。
- 冒烟：`http/auth.http` → `http/qa.http` → `http/bounty.http` 或 `scripts/smoke/`。
