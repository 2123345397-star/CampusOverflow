# 读模型、角色与外部系统（Dev-2 板块）

> 负责人：房国栋（Dev-2 · 前端与用户视角）
> 本文档回答：谁在操作（角色）、系统要查什么数据（读模型）、依赖哪些外部系统。

## 一、角色清单（4 个）

| 角色 | 权限范围 | 说明 |
|---|---|---|
| 访客 | 浏览问题列表、搜索、查看详情 | 未登录，最少权限，只能读不能写 |
| 注册用户 | 提问、回答、评论、投票、关注 | 登录后获得写权限 |
| 版主 | 删除内容、编辑标签、关闭问题 | 拥有管理权限，维护内容质量 |
| 定时任务 | 声誉结算、过期悬赏回收、通知发送 | 系统内部角色，无 UI |

## 二、外部系统清单（4 个）

| 外部系统 | 谁调用它 | 失败时怎么降级 |
|---|---|---|
| 邮件服务 | 注册验证、通知 | 失败不阻断主流程，用户可稍后重发验证邮件 |
| OAuth 提供商 | 第三方登录 | 失败回退到账号密码登录，不影响已有用户 |
| 对象存储 | 图片/附件上传 | 失败提示上传失败，允许发布纯文本内容 |
| 搜索服务 | 全文检索 | 失败回退到数据库 LIKE 查询，保证功能可用 |

## 三、读模型（5 个）

| 读模型名 | 服务的界面 | 关键字段 | 数据来源 |
|---|---|---|---|
| 问题列表 | 问题列表页 | 问题ID、标题、标签、回答数、票数、最后活跃时间 | 问题 + 回答 + 投票 |
| 问题详情 | 问题详情页 | 问题正文、回答列表、每答票数、是否已采纳、作者 | 问题 + 回答 + 投票 + 用户 |
| 用户主页 | 个人主页 | 声誉值、徽章、提问数、回答数 | 声誉账本 + 用户活动统计 |
| 通知中心 | 通知页 | 未读数、最近 20 条通知 | 通知记录 |
| 搜索结果 | 搜索页 | 匹配问题列表、关键词高亮 | 搜索索引 |
