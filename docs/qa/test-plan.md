# CampusOverflow Sprint 0 测试计划

> 负责人：青岑（QA）
> 范围：Lab1–Lab3 / V3 Sprint 0
> 版本：v1.0

## 1. 测试目标

验证 V3 Sprint 0 的认证、课程与环境冒烟链路，确认前端页面可打开，并记录 Q&A 尚未实现的部分为已知限制。

## 2. 测试范围

### 2.1 本轮覆盖

- 认证：CSRF、注册、登录、当前用户、登出
- 课程：课程列表、我的课程、加入课程、重复加入
- 前端：登录/注册页、问题列表页、问题详情页、提问页（课程选择）
- 工程：CI、分支保护、提交身份（流程核查）

### 2.2 本轮不覆盖

- 发布问题、回答、投票、评论、采纳的后端行为（Q&A 领域方法标 TODO(S2)，Sprint 2 实现）
- 声誉、搜索、通知、排行榜（Sprint 3）

## 3. 测试环境

- 后端：`mvn spring-boot:run -pl co-bootstrap -Dspring-boot.run.profiles=dev`
- 中间件：MySQL、Redis（`docker compose -f deploy/docker-compose.yml up -d mysql redis`）
- 前端：`npm run dev`（http://localhost:5173）
- 接口脚本：`http/auth.http`
- 浏览器：Chrome / Edge
