# CampusOverflow TeamX 团队章程 v1.0

## 1. 团队价值观
- 诚实沟通，问题早暴露；
- 代码可读优先于炫技；
- 对事不对人；
- 尊重角色，但不推卸责任。

## 2. 角色与职责
- PO：魏志国，负责 Backlog 与优先级；
- SM：陈明哲，刘俊琒，负责流程、看板、会议和障碍清除；
- Developer：青岑，房国栋；
- QA：青岑，兼 Developer。

## 3. 沟通约定
- IM 群：CampusOverflow-TeamX；
- 工作日 2 小时内回复群消息；
- 每日站会时间：12:30；
- 阻塞超过 2 小时必须在群内升级；
- 重要决策写入 docs/decisions/。

## 4. 开发规约
- main 禁止直推；
- 分支命名：feature/<姓名拼音>-<功能>；
- Commit 规范：feat/fix/docs/test/refactor: 描述；
- 每个 PR 至少 1 人 review，LGTM 后由 SM 合并；
- 新代码必须有单元测试；
- 不允许提交明文密码和密钥。

## 5. DoD 初版
一个任务完成必须满足：
1. 代码已提交并推送；
2. 通过编译和单元测试；
3. 至少 1 人代码评审通过；
4. 相关文档已更新；
5. 看板卡片移到 Done；
6. 无明文密钥、无调试残留。
