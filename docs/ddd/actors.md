# 角色与外部系统

> 负责人：青岑（Dev-1）

## 一、角色

| 角色 | 权限范围 |
|---|---|
| 访客 | 浏览问题、搜索、查看详情 |
| 注册用户 | 提问、回答、评论、投票、收藏 |
| 课程教师 / 助教 | 认证回答、管理课程成员、删除内容 |
| 管理员 | 禁用账号、全局管理 |
| 定时任务 | 悬赏过期、声誉结算、通知发送 |

## 二、外部系统

| 外部系统 | 调用方 | 失败降级 |
|---|---|---|
| 邮件服务 | 注册验证、通知 | 不阻断主流程，可稍后重发 |
| OAuth 提供商 | 第三方登录 | 回退账号密码登录 |
| 对象存储 | 图片/附件 | 提示上传失败，允许纯文本发布 |
| 搜索服务 | 全文检索 | 回退数据库 LIKE 查询 |
